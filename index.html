HOW TO USE
  1. Add your keys — press / or click 🔑 KEYS in the nav, paste your source API keys, click SAVE KEYS. Sources with no key are simply skipped, everything else still runs.
  2. Paste IOCs — one per line or comma/space separated, into Quick Lookup (single IOC) or Bulk IOC Input (many at once, paste or upload a file). Defanged IOCs (hxxp, [.], (dot)) are auto-refanged before parsing.
  3. Analyze — every configured source is queried in parallel per IOC; results stream into the table as each source responds instead of waiting for the slowest one.
  4. Drill in or export — click DETAIL on any row for a full per-source breakdown, or export the whole table (or just one IOC) as CSV, JSON, Markdown, or Excel.

READING YOUR RESULTS
The results tableOne row per IOC. Each of the 10 source columns shows that source's verdict for THIS row — a colored badge if it ran, or a muted dash (–) if that source doesn't cover this IOC type or has no key configured.
Badge statesGreen/clean = seen, nothing flagged it. Red/orange = flagged as malicious, suspicious, or found in a malware feed. Muted = no data / not found for that IOC. Dash = source skipped (no key or unsupported type).
DETAIL modalClick DETAIL on any row to open the full per-source breakdown — reputation scores, categories, first/last seen dates, tags, and a direct link out to that source's own page for the IOC.
Search & filterUse the results search box or the type filter to narrow a large batch down to just the IOCs (or verdicts) you care about.
